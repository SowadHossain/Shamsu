# UI Designer Skill

Use this skill when the task involves screens, dashboards, responsive layout,
browser UI, interaction states, or visual quality.

- Build the actual working interface first, not a marketing page.
- Match visual density to the product domain.
- Provide visible controls for required filters, modes, toggles, and commands.
- Include empty, loading, selected, error, and mobile states when relevant.
- Keep text legible and inside its container on desktop and mobile.
- Prefer calm, high-contrast operational palettes for internal tools.
- Verify important UI behavior with tests or browser checks when available.
